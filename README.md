# 『無限ねこパンチ！〜ネズミ大捕物帳〜』🐱🐾

無限に穴から湧き出てくるネズミたちを、可愛い猫ちゃんで次々と捕まえる爽快2Dアクションブラウザゲームです！
外部ライブラリや画像・音声ファイルのダウンロードは一切不要。HTML5 Canvasと純粋なモダンJavaScript、Web Audio APIによるシンセサイザー効果音を完全内蔵しています。

---

## 🎮 遊び方

### すぐに遊ぶ方法
1. 本フォルダにある [`index.html`](index.html) をGoogle Chrome、Microsoft Edge、Safariなどのブラウザで開くだけで即座にプレイできます！
2. または、ターミナルで本ディレクトリに移動し、Pythonの簡易サーバーを起動してブラウザでアクセスすることも可能です：
   ```bash
   python -m http.server 8000
   ```
   ブラウザで `http://localhost:8000` を開きます。

## 🕹️ 操作方法

| 操作 | マウス / タッチ | キーボード |
| :--- | :--- | :--- |
| **猫の移動** | カーソル / 指の位置に追従 | `W` `A` `S` `D` または `矢印キー` |
| **飛びつき（パウンス）** | 左クリック / 画面タップ | `Space` キー |
| **ポーズ（一時停止）** | 画面右上の ⏸️ ボタン | `P` または `Esc` キー |
| **全画面表示切替** | 画面右上の ⛶ ボタン | `F` キー |
| **サウンド切り替え** | 画面右上の 🔊/🔇 ボタン | - |

> 💡 **攻略のコツ＆ルール**:
> 1. **正面でのみ捕獲可能**: 猫は**自分の正面（前方扇形エリア）にいるネズミのみ**を捕まえられます。背後に触れても捕獲できないため、ネズミの方向へしっかり向き直しましょう！
> 2. **ネズミは正面に来ると逃げる**: ネズミは猫の正面（視界）に入ると「！」と驚いて逃げ出しますが、猫の背後や死角からは警戒せずチーズに忍び寄ってきます。
> 3. **全方位警戒と飛びつき**: チーズの上に居座るだけでは背後から食べられてしまいます。周囲を見渡し、忍び寄るネズミへ素早く振り向いて**飛びつき（クリック / Space）**で捕らえましょう！

## ⚡ 爽快システム

### 1. コンボ倍率システム
ネズミを2.2秒以内に連続捕獲するとコンボが繋がり、獲得スコアが **最大5倍** まで跳ね上がります！

### 2. マタタビ・フィーバータイム！
ネズミを捕まえてフィーバーゲージが100%になると発動！
- 猫の移動速度が1.6倍にUP
- 飛びつきのクールダウンなし
- 獲得スコアがさらに2倍（コンボと重複して超高得点！）
- 画面が七色に光り、ネズミたちが大パニックで湧き出します！

### 3. 選べる2つのゲームモード
1. **🧀 チーズ防衛モード（エンドレス）**:
   - 部屋中央のおいしいチーズをネズミたちのかじり攻撃から守り抜く耐久サバイバル！
   - チーズのHPが0%になるまで、無限に増え続けるネズミと勝負します。
2. **⏱️ 60秒タイムアタック**:
   - 制限時間60秒の間にどれだけ多くのネズミを捕獲してハイスコアを叩き出せるかを競います。

## 🛠️ 技術構成
- **描画**: HTML5 2D Canvas API（60fps requestAnimationFrame）
- **音声**: Web Audio API（猫の鳴き声、風切り音、ネズミの鳴き声、コンボ音程、ファンファーレ、BGMをリアルタイム波形合成）
- **デザイン**: CSS3（グラスモフィズム、レスポンシブ配置、レトロゲーム風アニメーション）
- **データ保存**: ブラウザの `localStorage` によりモード別ハイスコアと最大コンボ数を自動記録
