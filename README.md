# 『無限ねこパンチ！〜ネズミ大捕物帳〜』🐱🐾

無限に穴から湧き出てくるネズミたちを、可愛い猫ちゃんで次々と捕まえる爽快2Dアクションブラウザゲームです！
外部ライブラリや画像・音声ファイルのダウンロードは一切不要。HTML5 Canvasと純粋なモダンJavaScript、Web Audio APIによるシンセサイザー効果音を完全内蔵しています。

## 🎮 遊び方

### すぐに遊ぶ方法
1. 本フォルダにある [`index.html`](index.html) をGoogle Chrome、Microsoft Edge、Safariなどのブラウザで開くだけで即座にプレイできます！
2. または、ターミナルで本ディレクトリに移動し、Pythonの簡易サーバーを起動してブラウザでアクセスすることも可能です：
   ```bash
   python -m http.server 8000
   ```
   ブラウザで `http://localhost:8000` を開きます。

> 💡 **攻略のコツ＆ルール**:
> 1. **正面でのみ捕獲可能**: 猫は**自分の正面（前方扇形エリア）にいるネズミのみ**を捕まえられます。背後に触れても捕獲できないため、ネズミの方向へしっかり向き直しましょう！
> 2. **ネズミは正面に来ると逃げる**: ネズミは猫の正面（視界）に入ると「！」と驚いて逃げ出しますが、猫の背後や死角からは警戒せずチーズに忍び寄ってきます。
> 3. **全方位警戒と飛びつき**: チーズの上に居座るだけでは背後から食べられてしまいます。周囲を見渡し、忍び寄るネズミへ素早く振り向いて**飛びつき（クリック / Space）**で捕らえましょう！

### ⚔️ 兵装強化とオプション（護衛機）
敵編隊（赤ネズミ等）を撃破すると「肉球パワーカプセル」が出現します。
- **兵装ランク（すべて直進型レーザー！腕前が試される精密射撃）**:
  - **Lv.1**: 通常ツインビーム（2連射の平行直線ビーム）
  - **Lv.2**: 直線ロングレーザー（長めのシャープな直線光線がまっすぐ前へ敵を2体貫通！）
  - **Lv.3**: 超極太ハイパーロングレーザー（さらに長く太い高威力メガビームがまっすぐ前へ敵を5体貫通！）
  - ※広範囲攻撃を排した直進レーザー仕様のため、上下の軸合わせとエイムが攻略のカギとなります。
- **シャドウオプション（最大3機 / 本家グラディウス準拠の軌跡追従仕様）**:
  - 猫の飛行軌跡を忠実にトレースするオレンジの光球護衛機。
  - **停止時挙動の最適化**: 自機が移動している時のみ軌跡履歴が進むため、**自機が静止した際はオプションもその場（自機後方のオフセット位置）に留まり、自機に重なることがありません**。上下に旋回して止まることでオプションを縦一列に配置し、多段レーザー壁を展開するグラディウス伝統の戦術が可能です！
  - 猫と同じ直進レーザーを一斉射撃するだけでなく、**敵の弾丸を吸収・無効化するバリアシールド**としても機能します！
- **🚀 対地兵器（2-Way地形走破ミサイル）**:
  - 初期状態では未装備ですが、**兵装ランクがLv.2以上のときに `R` キー（または画面下部ボタン）を押すと、兵装ランクを1段階消費（生贄）して対地兵器をアンロック**できます！
  - 解放後は上下斜め方向へ2発のロケットを発射。地面や天井の斜面に激突すると滑走ミサイルへと変形し、**地形の起伏に沿って火花を散らしながら疾走**します。
  - レーザーでは狙いにくい天井や床面を這う敵（ダッカー型クローラー）や下方の敵を自動的に迎撃・破壊できます。
  - **発射仕様（セミオート方式）**: メインレーザー（Space長押し連射）とは異なり、対地兵器は**Spaceキー（またはクリック/タップ）を1回押すごとに1回発射**されます。長押し連射によるミサイルの乱射を防ぎ、狙いたいタイミングで精密に地面・天井へ投下できます。
  - 解放後は `R` キーでいつでもON/OFFを切り替え可能です（再切り替え時にランク消費はありません）。
- **⚡ 連射制限（3発バースト）とオーバーヒート（50発制限・3秒クールダウン）**:
  - **3発ごとの連射制限**: キー押しっぱなしで射撃を続ける際、**3発撃つごとに一瞬の間（ウェイト）が空くバースト射撃仕様**になりました。むやみなフルオート乱射を防ぎ、リズミカルなトリガー操作が楽しめます。
  - **オーバーヒート（50発制限）**: レーザーは**50発撃つごとに3秒間のクールダウン（オーバーヒート状態）**が必要となります。
  - クールダウン中の3秒間はメインレーザー・対地兵器の発射が一切できなくなるため、無駄撃ちを避けるか、オプションの盾を活用して敵弾や体当たりを回避・防御する必要があります！
  - HUD上には残り弾数（ENERGY）が表示され、オーバーヒート時には警告音とともに頭上およびHUDへカウントダウンタイマーと冷却バーが表示されます。3秒経過すると武器が自動リチャージされます。
- **💚 回復アイテム（リペアカプセル / 各ステージ約1個出現の絶妙なバランス）**:
  - 自機の初期体力は**ハート3個（❤️❤️❤️ / 3HP）**！
  - 全快ではなく**体力の一部（1HP）を回復**する新アイテム「リペアポッド（エメラルドグリーンに輝くハートカプセル）」が登場！
  - **ステージに1個程度の出現バランス（ステージ＝ボス1機撃破までの区間）**:
    - 各ステージ内で回復アイテムは原則**1個まで**出現するように調整されています。
    - **ステージ1の出現タイミング**: ゲーム開始直後の序盤（0〜850 LY）は自機の武装・オプション強化を最優先するため回復アイテムは出現せず、**ステージ1後半（850 LY以降）から登場**します！
    - 通常敵撃破時（自機負傷時は高確率、満タン時も一定確率）にステージ中未出現であればドロップ。
    - 道中で未出現のままボスを撃破した場合は、ボス撃破時に**パワーカプセルとリペアカプセルの2個が同時ドロップ**され、次ステージへ向けて補給できます（道中で既に出現済みの場合はパワーカプセル2個）。
    - ボスを倒して次のステージに進むと回復ポッド出現制限はリセットされます。
  - **序盤のパワーカプセル出現率大幅UP（開幕ロケットスタート）**:
    - ゲーム開始直後（ステージ1前半や初期状態時）は、**最初の3ウェーブでパワーポッド持ちの赤敵が確定出現**し、その後も赤敵編隊の出現率が約80%に大幅アップ！序盤から素早くオプションやLv.2/Lv.3レーザー、対地兵器を解放して爽快なシューティングを堪能できます。
  - **満タン時のボーナス**: 体力が最大（3HP）の状態で取得した場合は、無駄にならず**+2500点**のハイスコアボーナスを獲得できます。
- **🎯 ボス弾の精密輪郭当たり判定（究極のカスり・見切り回避）**:
  - ボスの放つ大口径プラズマ弾のグラフィックに白と橙のエッジリング（境界線）を描画し、**当たり判定を表示されている弾丸の輪郭サイズに厳密に一致**させました。
  - さらに自機本体も傾き（tilt）に追従する楕円コア判定（ミンコフスキー和による接触計算）を採用。しっぽやヒゲ先などの飾り部分による理不尽な被弾を排除し、**1ドットの隙間を見切って敵弾をすり抜けるスリリングなカスり回避（グレイズ）**が存分に楽しめます！
- **🔄 画期的なトレードシステム**:
  - 戦況に応じて、`Q` キーで**兵装ランク1段階をオプション1機に変換**！
  - 逆に `E` キーで**オプション1機を削って兵装ランクを1段階UP**！
  - プレイスタイルやボス戦に合わせてリアルタイムに機体をカスタマイズできます。

### 👾 魔界の敵キャラクターたち
ステージを進む（踏破距離が伸びる）につれて、カラスや赤いコウモリネズミの出現割合が増加していきます。

1. 🧟 **ゾンビネズミ (ZombieMouse)**:
   - 墓場の黒土から無限に這い出してくる腐敗ネズミ。
   - **一撃必殺**: どの武器（槍・短剣・松明）を当てても**一撃で粉砕**できます（HP1 / 100点）。
   - 前方の土から湧くだけでなく、油断していると**背後の土からも奇襲**してくるため挟み撃ちに注意！
2. 🦅 **カラス (GraveyardCrow)**:
   - 枯れ木や十字架の上に止まってプレイヤーを凝視している不気味な黒カラス（HP1 / 200点）。
   - **フェイント機動**: プレイヤーが近づくと、**「一旦反対方向に少し飛んでから」**急降下を開始し、地上スレスレを**低空飛行で猛スピード水平突進**してきます！
   - 引きつけてジャンプ武器投げ、またはしゃがみ撃ちで迎撃しましょう。
3. 🦇 **赤いコウモリネズミ (RedBatMouse / レッドアリーマー風)**:
   - 巨大な深紅の蝙蝠羽を持つ魔界のエリート悪魔ネズミ（HP5 / 1000点）。
   - **変幻自在の空中機動**:
     - 高空で妖しくホバリング索敵（lurking）
     - プレイヤーを捕捉すると威嚇咆哮（「👹 ギニャアァッ！」）とともに斜め下方へ超高速**急降下滑空ダイブ（dive）**！
     - 地面スレスレに達すると目にも留まらぬ速さで**水平低空突進（ground_rush）**！
     - プレイヤーの攻撃をすり抜けながら垂直に大空へ**急上昇退避（soar_up）**！
   - 手ごわい強敵ですが、倒すと**確定で宝の壺（🏺）をドロップ**します！

## 🛠️ 技術構成
- **描画**: HTML5 2D Canvas API（60fps requestAnimationFrame、星空多重パララックス、シャドウトレース補間、墓場パララックス背景）
- **音声**: Web Audio API（猫の鳴き声、レーザー発射音、ノイズ爆発音、ワープ変調トレード音、警報サイレン、魔界村風ゴシックBGM＆専用SEを完全リアルタイム波形合成）
- **デザイン**: CSS3（グラスモフィズム、レスポンシブ配置、レトロゲーム風アニメーション）
- **データ保存**: ブラウザの `localStorage` によりモード別ハイスコア（通常・タイムアタック・シューティング・ニャ界村）を自動記録
