# 『無限ねこパンチ！〜ネズミ大捕物帳〜』🐱🐾

無限に穴から湧き出てくるネズミたちを、可愛い猫ちゃんで次々と捕まえる爽快2Dアクションブラウザゲームです！
外部ライブラリや画像・音声ファイルのダウンロードは一切不要。HTML5 Canvasと純粋なモダンJavaScript、Web Audio APIによるシンセサイザー効果音を完全内蔵しています。

---

## 🎮 遊び方

### すぐに遊ぶ方法
1. 本フォルダにある [`index.html`](index.html) をGoogle Chrome、Microsoft Edge、Safariなどのブラウザで開くだけで即座にプレイできます！
2. または、ターミナルで本ディレクトリに移動し、Pythonの簡易サーバーを起動してブラウザでアクセスすることも可能です：
   ```bash
   python -m http.server 8000
   ```
   ブラウザで `http://localhost:8000` を開きます。

## 🕹️ 操作方法

| 操作 | マウス / タッチ | キーボード |
| :--- | :--- | :--- |
| **猫の移動** | カーソル / 指の位置に追従 | `W` `A` `S` `D` または `矢印キー` |
| **飛びつき（パウンス）** | 左クリック / 画面タップ | `Space` キー |
| **ポーズ（一時停止）** | 画面右上の ⏸️ ボタン | `P` または `Esc` キー |
| **全画面表示切替** | 画面右上の ⛶ ボタン | `F` キー |
| **サウンド切り替え** | 画面右上の 🔊/🔇 ボタン | - |

> 💡 **攻略のコツ＆ルール**:
> 1. **正面でのみ捕獲可能**: 猫は**自分の正面（前方扇形エリア）にいるネズミのみ**を捕まえられます。背後に触れても捕獲できないため、ネズミの方向へしっかり向き直しましょう！
> 2. **ネズミは正面に来ると逃げる**: ネズミは猫の正面（視界）に入ると「！」と驚いて逃げ出しますが、猫の背後や死角からは警戒せずチーズに忍び寄ってきます。
> 3. **全方位警戒と飛びつき**: チーズの上に居座るだけでは背後から食べられてしまいます。周囲を見渡し、忍び寄るネズミへ素早く振り向いて**飛びつき（クリック / Space）**で捕らえましょう！

## ⚡ 爽快システム

### 1. コンボ倍率システム
ネズミを2.2秒以内に連続捕獲するとコンボが繋がり、獲得スコアが **最大5倍** まで跳ね上がります！

### 2. マタタビ・フィーバータイム！
ネズミを捕まえてフィーバーゲージが100%になると発動！
- 猫の移動速度が1.6倍にUP
- 飛びつきのクールダウンなし
- 獲得スコアがさらに2倍（コンボと重複して超高得点！）
- 画面が七色に光り、ネズミたちが大パニックで湧き出します！

### 3. 選べる3つのゲームモード
1. **🧀 チーズ防衛モード（エンドレス）**:
   - 部屋中央のおいしいチーズをネズミたちのかじり攻撃から守り抜く耐久サバイバル！
   - チーズのHPが0%になるまで、無限に増え続けるネズミと勝負します。
2. **⏱️ 60秒タイムアタック**:
   - 制限時間60秒の間にどれだけ多くのネズミを捕獲してハイスコアを叩き出せるかを競います。
3. **🚀 シューティングモード（宇宙ニャンディウス / グラディウス風）**:
   - ファミコン名作『グラディウス』のパロディ横スクロールシューティング！
   - 透明な宇宙ヘルメットをかぶり、前足を伸ばして宇宙を飛翔する「横から見た猫」を操り、ネズミ帝国や巨大ボスと無限のハイスコアアタックに挑みます。

## 🚀 宇宙ニャンディウス（シューティングモード詳細）

### 🕹️ シューティングの操作方法
| 操作 | キーボード | マウス / タッチ |
| :--- | :--- | :--- |
| **猫の移動** | `W` `A` `S` `D` / `矢印キー` | マウス移動 / タッチ追従 |
| **ショット（連射）** | `Space` キー（押しっぱなしで自動連射） | 画面クリック / ホールド |
| **兵装 ➔ オプション トレード** | `Q` キー | HUDの「Q: 兵装➔機」ボタン |
| **オプション ➔ 兵装 トレード** | `E` キー | HUDの「E: 機➔兵装」ボタン |

### ⚔️ 兵装強化とオプション（護衛機）
敵編隊（赤ネズミ等）を撃破すると「肉球パワーカプセル」が出現します。
- **兵装ランク（すべて直進型レーザー！腕前が試される精密射撃）**:
  - **Lv.1**: 通常ツインビーム（2連射の平行直線ビーム）
  - **Lv.2**: 直線ロングレーザー（長めのシャープな直線光線がまっすぐ前へ敵を2体貫通！）
  - **Lv.3**: 超極太ハイパーロングレーザー（さらに長く太い高威力メガビームがまっすぐ前へ敵を5体貫通！）
  - ※広範囲攻撃を排した直進レーザー仕様のため、上下の軸合わせとエイムが攻略のカギとなります。
- **シャドウオプション（最大3機）**:
  - 猫の飛行航跡を少し遅れて追従するオレンジの光球護衛機。猫と同じ直進レーザーを一斉射撃するだけでなく、**敵の弾丸を吸収・無効化するバリアシールド**としても機能します！
- **🔄 画期的なトレードシステム**:
  - 戦況に応じて、`Q` キーで**兵装ランク1段階をオプション1機に変換**！
  - 逆に `E` キーで**オプション1機を削って兵装ランクを1段階UP**！
  - プレイスタイルやボス戦に合わせてリアルタイムに機体をカスタマイズできます。

### 👑 巨大ボスとの死闘
一定航行距離ごとに、警告サイレン（WARNING!!）とともに巨大ボスが襲来！
- **巨大戦艦メカデカチュウ**: チーズキャノン斉射と回転コアシールドを備えた超弩級戦艦。
- **巨大宇宙カエル ケロケロス**: 画面端まで伸びるロケット舌突進とケロケロ全方位弾幕を放つ宇宙生物。
- ボスを撃破すると大量スコアと複数のパワーカプセルを獲得できます！

## 🛠️ 技術構成
- **描画**: HTML5 2D Canvas API（60fps requestAnimationFrame、星空多重パララックス、シャドウトレース補間）
- **音声**: Web Audio API（猫の鳴き声、レーザー発射音、ノイズ爆発音、ワープ変調トレード音、警報サイレン、BGMを完全リアルタイム波形合成）
- **デザイン**: CSS3（グラスモフィズム、レスポンシブ配置、レトロゲーム風アニメーション）
- **データ保存**: ブラウザの `localStorage` によりモード別ハイスコア（通常・タイムアタック・シューティング）を自動記録
